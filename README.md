# Aim Trainer A56
Entrenador de puntería independiente para Android. No interactúa con Free Fire.

## Compilación
En GitHub: Actions > Compilar APK > Run workflow.
Descargar el artifact Aim-Trainer-A56-debug-apk al terminar.

Proyecto inicial de prueba: objetivos móviles, aciertos, disparos a cabeza y precisión.
